# The Turn Performance Golf Club — Website

Static site (HTML/CSS). No build step required.

## Deploy with GitHub Pages
1. Create a new repository and upload the entire contents of this folder to the repo root (keep the `fonts/` subfolder intact).
2. In the repo: **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then **Save**.
4. Your site publishes at `https://<username>.github.io/<repo>/` (allow a minute or two).

To use a custom domain (e.g. theturnpgc.com), add it under **Settings → Pages → Custom domain**.

## Notes
- `index.html` is the landing page.
- Filenames are case-sensitive on GitHub Pages — keep them exactly as-is.
